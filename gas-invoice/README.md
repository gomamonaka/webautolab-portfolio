# gas-invoice — 請求書の自動作成ツール（Google Apps Script）

スプレッドシートに請求データを入力しておくと、**請求書の転記 → PDF 化 → Gmail の下書き作成**までを一括で自動化する Google Apps Script（GAS）のデモです。

月末の請求書発行で発生する「テンプレートへの転記」「金額・消費税の計算」「PDF への変換と保存」「メールへの添付と文面作成」といった繰り返し作業を、メニュー 1 クリックに置き換えます。送信は行わず **下書きまで** を作るので、人は内容を確認して送信ボタンを押すだけです。

## 自動化される流れ

1. 「請求データ」シートの行を読み取り、**請求先 ＋ 請求日** ごとにグループ化（1 グループ ＝ 請求書 1 枚）
2. 請求書番号を自動採番（例：`INV-202611-001`）
3. 「請求書テンプレート」シートの複製に、請求先・明細・金額を転記
4. 小計・消費税（切り捨て）・合計を計算
5. テンプレートを PDF 化し、Google Drive の「請求書PDF」フォルダへ保存
6. PDF を添付した Gmail の **下書き** を作成
7. 処理した行に請求書番号を書き戻し（＝処理済みの印）、「処理ログ」シートへ結果を記録

請求書番号が入っている行は処理済みとしてスキップされるため、追加分のデータだけを対象に何度でも実行できます。

## 手作業との比較（試算）

以下の前提で試算した目安です（実測値ではありません）。

**試算の前提**

- 手作業 1 件あたり：テンプレートへの転記・金額計算 15 分 ＋ PDF 変換・保存 3 分 ＋ メール作成・添付 2 分 ＝ 約 20 分
- 自動化後 1 件あたり：実行と下書きの確認で約 1 分
- 月の請求書発行件数：10 件

| | 手作業 | 自動化後 |
|---|---|---|
| 1 件あたり | 約 20 分 | 約 1 分 |
| 月 10 件 | 約 200 分（3 時間 20 分） | 約 10 分 |
| 年間換算 | 約 40 時間 | 約 2 時間 |

転記ミス・計算ミス・添付漏れといったヒューマンエラーの削減効果は、上記の時間換算には含めていません。

## セットアップ手順

### 1. スプレッドシートを用意する

新規の Google スプレッドシートを作成し、次の 2 シートを用意します（「処理ログ」シートは初回実行時に自動作成されます）。

| シート名 | 役割 |
|---|---|
| `請求データ` | 請求先と明細を入力するシート |
| `請求書テンプレート` | 請求書のレイアウト（雛形） |
| `処理ログ` | 実行結果の記録（自動作成） |

### 2. 「請求データ」シートを作る

同梱の `sample-invoice-data.csv` を取り込むのが簡単です。

1. スプレッドシートのメニューから「ファイル」→「インポート」
2. `sample-invoice-data.csv` をアップロードし、インポート先を「現在のシートを置換」などにして取り込む
3. シート名を `請求データ` に変更する

列構成は次のとおりです。同じ請求先・同じ請求日の行が 1 枚の請求書にまとまります。

| 列名 | 内容 |
|---|---|
| 請求先会社名 | 請求書の宛先 |
| 担当者名 | メール本文の宛名に使用 |
| メールアドレス | 下書きの宛先 |
| 請求日 | 発行日。あわせてグループ化のキー |
| 支払期限 | 請求書とメール本文に表示 |
| 品目 | 明細行の品目名 |
| 数量 | 明細行の数量 |
| 単位 | 式・時間・個 など |
| 単価 | 明細行の単価（税抜） |
| 請求書番号 | 空欄＝未処理。実行後に自動で書き込まれる |

### 3. 「請求書テンプレート」シートを作る

請求書の見た目を用意します。スクリプトは下記のセル位置に値を書き込むので、レイアウトを組む際の目安にしてください（セル位置は `Code.gs` の `CONFIG.CELLS` で変更できます）。

| セル | 書き込まれる内容 |
|---|---|
| B2 | 請求先会社名（「御中」付き） |
| G2 | 請求書番号 |
| G3 | 発行日 |
| G4 | 支払期限 |
| B7〜B18 | 品目（最大 12 行） |
| D7〜D18 | 数量 |
| E7〜E18 | 単位 |
| F7〜F18 | 単価 |
| G7〜G18 | 金額（数量 × 単価） |
| G20 | 小計 |
| G21 | 消費税 |
| G22 | 合計金額 |
| B20 | 発行者情報 |
| B24 | 振込先 |

6 行目は明細の見出し行として使います。金額セルには表示形式「#,##0」などを設定しておくと、そのまま請求書らしい見た目になります。

### 4. スクリプトを貼る

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. エディタの内容をすべて消し、`Code.gs` の内容を貼り付けて保存する
3. スプレッドシートに戻って再読み込みすると、メニューに「請求書ツール」が追加される

### 5. 発行者情報を書き換える

`Code.gs` の `CONFIG.ISSUER`（発行者名・住所・メールアドレス・振込先）と、必要に応じて `CONFIG.TAX_RATE`、`CONFIG.MAIL_SUBJECT`、`CONFIG.MAIL_BODY` を自社の内容に書き換えます。

### 6. 初回承認

初回実行時は、Google Drive と Gmail へのアクセス承認を求められます。「詳細」→「（プロジェクト名）に移動」と進み、権限を確認して許可してください（自分が作成したスクリプトに対してのみ許可するものです）。

## 使い方

1. 「請求データ」シートに請求先と明細を入力する（請求書番号の列は空欄のまま）
2. メニュー「請求書ツール」→「未処理の請求書を作成（PDF＋下書き）」を実行する
3. Drive の「請求書PDF」フォルダに PDF が保存され、Gmail に下書きが作成される
4. 下書きの内容を確認して送信する
5. 処理結果は「処理ログ」シートで確認できる

## カスタマイズ例

- **自社の請求書フォーマットに合わせる**：テンプレートシートにロゴや色付けを用意し、`CONFIG.CELLS` のセル位置を自社レイアウトに合わせて変更する
- **メール文面の変更**：`CONFIG.MAIL_SUBJECT` / `CONFIG.MAIL_BODY` を書き換える。`{customerName}` `{invoiceNumber}` `{total}` `{dueDate}` などのプレースホルダが使える
- **税率・端数処理**：軽減税率の対象がある場合は `CONFIG.TAX_RATE` の変更や、消費税の計算箇所（切り捨て／四捨五入）の調整
- **明細行数を増やす**：テンプレートの明細エリアと `CONFIG.CELLS.ITEM_MAX_ROWS` をあわせて変更する
- **毎月末の自動実行**：Apps Script のトリガーに `createInvoices` を月次で登録しておくと、下書きまで自動で用意される（送信前の確認は人が行う運用のまま）
- **控えの共有**：PDF の保存先フォルダを共有ドライブに変更し、経理担当と自動で共有する

## 注意点

- GAS の 1 回の実行時間には上限（約 6 分）があるため、件数が多い場合は「請求データ」を分けて複数回実行してください
- このデモは下書き作成までで、メールの自動送信は行いません
