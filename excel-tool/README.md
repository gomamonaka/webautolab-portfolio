# Excel/CSVデータ整形・レポート自動化サンプル

このフォルダは、ココナラ出品「**Excel/CSVデータ整形・レポート自動化**」のポートフォリオ用サンプル一式です。
実務でよくある「バラバラな表記の売上データ」を想定した架空データを使い、

- 汚いCSVを自動で綺麗に整形
- 見やすい集計・グラフ付きのExcelレポートを自動生成

する処理を、Python (標準ライブラリ + openpyxl のみ) で実装しています。特別な環境構築なしにそのまま動かせます。

## できること

1. **表記ゆれ・入力ミスだらけのCSV** (`input/売上データ_raw.csv`) を読み込み
2. 以下を自動的にクリーニング
   - 日付表記の統一 (`2026/1/5` `2026-01-05` `令和8年1月5日` `1/5` → すべて `YYYY-MM-DD`)
   - 全角数字→半角数字への変換 (`２６` → `26`)
   - セル前後の余分な空白の除去
   - 完全に同じ内容の重複行の削除
   - 空行の削除
   - 商品名の表記ゆれ統一 (`コーヒー豆` `珈琲豆` `ｺｰﾋｰ豆` などを1つの名称に統一)
   - `1,200円` `¥1200` のようなテキスト単価を数値に変換
3. 整形結果を **`output/売上レポート.xlsx`** として出力
   - **整形済データ**: ヘッダー装飾つきのExcelテーブル形式、列幅自動調整、日付・金額の表示形式設定済み
   - **月別集計**: 月ごとの売上集計表 + 棒グラフ
   - **商品別集計**: 商品ごとの売上集計 (売上高の多い順に並べ替え、合計行つき)
   - **クリーニングログ**: 何件の重複を消したか、何件の日付を直したか等の作業記録

## ファイル構成

```
excel-tool/
├── make_sample_data.py     # 汚いサンプルCSVを生成するスクリプト
├── clean_and_report.py     # CSVを整形してExcelレポートを出力するスクリプト
├── input/
│   └── 売上データ_raw.csv   # 生成される「汚い」元データ (約300行)
├── output/
│   └── 売上レポート.xlsx    # 生成される整形済みレポート (4シート構成)
└── README.md
```

## 実行方法

事前に openpyxl が必要です (未インストールの場合のみ):

```bash
pip install openpyxl
```

サンプルデータの生成 → クリーニング・レポート出力の順に実行します。

```bash
python make_sample_data.py
python clean_and_report.py
```

実行後、`output/売上レポート.xlsx` が生成されます。`clean_and_report.py` の実行時に、以下のようなクリーニング結果のログがコンソールにも表示されます。

## カスタマイズについて

ご依頼いただく際は、以下のような点をお客様のデータに合わせて調整いたします。

- 列名・列数の変更 (在庫数、支店名、担当部署など)
- 日付の年省略時の補完ルール (当年扱い／直近の日付から推定 など)
- 商品名・取引先名などの表記ゆれ統一辞書のカスタマイズ
- 集計軸の追加 (担当者別、顧客別、四半期別など)
- グラフの種類・デザインの変更
- 複数CSVファイルの一括取り込み・結合

## 動作環境

- Python 3.9以降 (標準ライブラリ + `openpyxl` のみ、`pandas` 不要)
- Windows / macOS / Linux で動作確認可能 (出力ファイルはExcel 2010以降で開けます)
