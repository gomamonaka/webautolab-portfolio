# 備品貸出管理アプリ（デモ）

社内の備品（PC・会議機材・工具など）の貸出と返却を、ブラウザで管理できる小規模Webアプリです。
「誰が・何を・いつまで借りているか」が一目で分かり、返却期限を過ぎた貸出は赤く強調表示されます。

> このような社内ツールを、要件を聞き取って短期間で構築できます。
> 「Excelや紙で管理していて限界を感じている」「貸出状況を共有したい」といったご相談の、たたき台としてご覧ください。

※ 本デモに含まれる備品名・人名・日付はすべて架空のサンプルデータです。実在の企業・個人の情報は含まれていません。

## できること（機能一覧）

| 機能 | 内容 |
|---|---|
| 備品の一覧表示 | 分類・総数・貸出中の点数と、「貸出可／在庫なし」の状態を一覧表示 |
| 備品の登録・編集・削除 | 備品名・分類・総数・メモを管理（貸出中の備品は誤って消せない仕組み付き） |
| 貸出の記録 | 借りた人と返却期限を指定して貸出を登録。在庫がない備品は貸出不可 |
| 返却の記録 | 貸出中一覧からワンクリックで返却済みに |
| 期限切れの強調表示 | 返却期限を過ぎた未返却の貸出を、赤い行とバッジで強調 |
| キーワード検索 | 備品名・分類・メモを対象に絞り込み検索 |
| CSVエクスポート | 貸出履歴（状態つき）をCSVでダウンロード。Excelで開ける形式（BOM付きUTF-8） |

## 起動方法

必要なのは Python 3 だけです。外部ライブラリのインストールは不要です。

```bash
python3 app.py
```

起動したら、ブラウザで http://localhost:8000 を開いてください。
初回起動時にサンプルデータ（備品10件・貸出記録10件）が自動で入ります。
データは同じフォルダの `equipment.db`（SQLite）に保存され、再起動しても残ります。
最初から試したい場合は `equipment.db` を削除して再起動してください。

## 画面の説明

- **備品一覧**：各備品の貸出状況が分かります。「貸出する」から貸出登録へ、「編集」から備品情報の変更・削除ができます。上部の検索欄でキーワード絞り込みも可能です。
- **貸出中の一覧**：現在貸し出している備品の一覧です。返却期限を過ぎたものは行全体が赤くなり、「期限切れ」バッジが付きます。「返却する」ボタンで返却を記録します。
- **貸出一覧をCSVで出す**：貸出履歴全体をCSVでダウンロードできます。月次の棚卸しや確認作業に使えます。

## テスト

業務ロジック（貸出・返却・期限切れ判定など）の単体テストを用意しています。

```bash
python3 -m unittest discover -s tests -v
```

## 技術構成

- Python標準ライブラリのみ（`http.server` + `sqlite3`）／外部依存なし
- データベース：SQLite（ファイル1つで完結、サーバー構築不要）
- 画面：HTML/CSSをアプリ内に埋め込み（フレームワークなし）

実案件では、ご要望に応じて「利用者ごとの権限管理」「返却期限前のメール通知」「複数拠点対応」などの追加も可能です。まずは現状の管理方法をお聞かせください。
