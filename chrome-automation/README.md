# Chromeの定型作業を1クリックで自動化（デモ）

Chrome拡張機能（Manifest V3）によって、社内システムでよくある「一覧をCSVに書き出す」「CSVを見ながら1件ずつフォームに転記する」といった定型作業をワンクリックで済ませるデモです。動作確認用に、実在しない架空データのみで構成したダミー顧客管理システム（`demo-crm/`）を同梱しています。

## できること（Before → After）

- **Before**: 顧客一覧を見ながらExcelに手作業で転記 / CSVの内容を1行ずつ見て新規登録フォームに手入力
- **After**:
  - 顧客一覧ページ右下のツールバーから「一覧をCSV保存」を押すだけで `customers_export.csv`（UTF-8 BOM付き、Excelでそのまま開ける）をダウンロード
  - 新規登録ページで「CSVから自動入力」を押してCSVファイルを選ぶだけで、1行目の内容がフォームに自動入力される。「次の行」で1件ずつ進める、「全件登録」でCSVの全行を自動で連続登録（入力→登録ボタン押下→完了トースト待ち、を行ごとに繰り返す）

## 構成

```
chrome-automation/
├── demo-crm/            # ダミーの顧客管理システム（Chrome拡張の動作確認用）
│   ├── index.html       # 顧客一覧（30件のダミーデータ + localStorageの新規登録分）
│   ├── new.html          # 新規顧客登録フォーム
│   ├── style.css
│   └── data/customers.js
├── extension/            # Chrome拡張機能本体
│   ├── manifest.json
│   ├── content.js / content.css   # フローティングツールバー本体
│   ├── lib/csv.js                 # 依存ライブラリなしのCSVパーサー/シリアライザ
│   ├── popup.html / popup.js      # 拡張機能アイコンから開くポップアップ
│   ├── icons/                     # 16/48/128px アイコン
│   └── sample/customers_import.csv  # 動作確認用サンプル（10件）
└── preview.png           # ポートフォリオ掲載用のイメージ画像
```

## インストール手順（開発者モードで読み込む）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、この `chrome-automation/extension` フォルダを選択する
4. 拡張機能一覧に「WebAutoLab 1クリック自動化(デモ)」が追加されれば完了

### 動作確認の流れ

1. `demo-crm/index.html` をブラウザで開く（ローカルサーバー経由、または本リポジトリのGitHub Pages上のURL）
2. 右下に浮かぶツールバーの「一覧をCSV保存」をクリック → `customers_export.csv` がダウンロードされる
3. 「＋新規登録」から `demo-crm/new.html` を開く
4. ツールバーの「CSVから自動入力」→ `extension/sample/customers_import.csv` を選択 → 1行目がフォームに自動入力される
5. 「次の行」で1件ずつ確認、または「全件登録」でCSVの10件を自動で連続登録（登録するたびに成功トーストが表示される）

拡張機能アイコンをクリックすると同じ操作をポップアップからも実行できます。

## 対応範囲 / 対象外

**対応範囲**
- 一覧ページのテーブル内容をCSVへエクスポート
- CSVを読み込んでフォームへ自動入力・連続登録
- 本デモと同じ構造（入力欄のid、テーブル構造）を持つ社内システムへの移植・カスタマイズ（別途ご相談）

**対象外（このデモでは扱いません）**
- CAPTCHA・reCAPTCHA等のbot対策の回避
- 利用規約・robots.txt等に反するアクセスや自動操作
- 決済処理の完全自動化（カード情報の自動入力・自動決済など）
- ログイン認証情報の保存・自動入力（本人の意思で行う操作の代行を超える自動化）

## 注意事項

- `demo-crm` 内のデータはすべて架空の会社名・氏名・連絡先であり、実在の個人・団体とは関係ありません。

## 設定画面

拡張機能のポップアップで「設定画面を開く」、または Chrome の拡張機能の詳細から設定画面を開きます。対象URLパターン（1行1件）、一覧のテーブル・ヘッダー行・データ行のCSSセレクター、出力列、CSV列名と入力CSSセレクターの対応、ツールバー表示を編集し「設定を保存」を押してください。保存後は対象ページを再読み込みします。

出力列は画面の順番でCSVに出力されます。列番号は1から数え、列名が空欄なら指定ヘッダー行のセルを使います。「行の属性」が空欄ならデータセルの文字列を出力します。初回は従来の demo-crm のURL・セレクター・data-* 属性・列順を chrome.storage.sync に保存します。「設定をリセット」で初期値へ戻せます。

「設定をJSONで書き出し」は編集欄の設定を保存し、「設定をJSONで読み込み」は検証後に編集欄へ反映します。読み込み後は「設定を保存」で確定します。設定は Chrome の同期ストレージを使用し、容量超過などの保存失敗は画面に表示されます。

対象URLは HTTP／HTTPS に対応し、ホスト・パスの * と localhost のポート番号を指定できます。コード変更なしで対象を追加できるよう、拡張機能の実行範囲は HTTP／HTTPS 全体とし、保存したURLパターンに一致する場合だけ自動化を有効にします（[Chrome公式のコンテンツスクリプト仕様](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)）。更新後は chrome://extensions で拡張機能を再読み込みしてください。

ツールバー非表示でもポップアップから一覧保存・CSVの先頭行の自動入力ができます。複数行を進める場合はツールバーを表示してください。「全件登録」は従来の demo-crm の登録ボタン・完了通知を使うため demo-crm フォーム専用です。
