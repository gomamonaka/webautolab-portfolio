# 予約・受付システム デモ（小規模店舗・教室向け）

紙の予約台帳や電話受付で回している予約業務を、そのまま Web 化するイメージで作ったデモアプリです。
「うちの店でもこういうのが欲しい」というご相談の参考例として公開しています。要件を聞き取って、こうした小規模システムを短期間で構築できます。

## できること

- **お客様向け予約フォーム**：メニュー・日付・時間を選んで予約を送信
- **空き枠の表示**：日付を選ぶと、その日の空いている時間枠だけが表示されます
- **二重予約の防止**：同じ日時に確定系の予約が入っている枠は選べません（キャンセルされた枠は再び空きます）
- **管理画面**：日付別の予約一覧、ステータスの変更（仮予約→確定→来店済み／キャンセル）
- **リマインド文面の自動生成**：予約ごとに、メールや LINE にコピーして使えるリマインド文面の下書きを自動で作ります（このデモでは実際の送信はしません。送信前に人が確認する設計が基本です）

## 起動方法

Python 3 だけで動きます（外部ライブラリ不要）。

```bash
python3 app.py
```

ブラウザで http://localhost:8000 を開いてください。

- `/` … お客様向けの予約ページ（空き枠表示＋予約フォーム）
- `/admin` … 店舗側の管理画面（予約一覧・ステータス変更）
- `/admin/reminder?id=<予約番号>` … リマインド文面の下書き表示

初回起動時に、メニュー4件・予約10件の**架空のサンプルデータ**が自動で入ります（日付は起動日を基準にした相対日付なので、いつ起動しても「今日・明日」の予約が見られます）。実在の店舗・人物のデータは含まれていません。

## 技術メモ

- Python 標準ライブラリのみ（`http.server` + `sqlite3`）
- 単体テスト9件（`tests/`）：二重予約の防止、ステータス遷移のルール、リマインド文面の生成などを検証
  - 実行：`python3 -m unittest discover -s tests`
- 実運用では、ログイン認証・メール送信・決済連携などを要件に合わせて追加します
