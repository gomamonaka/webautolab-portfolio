# LINE×AI返信デモ（シミュレーター）

LINE公式アカウントの問い合わせ対応を、ブラウザ上で再現するデモです。
**実LINE・実LLMには接続していません。** 返信の下書きは、キーワード判定によるルールベースの疑似AIが生成します。データはすべて架空のサンプル（店舗名は「サンプルサロン」）です。

## 体験できること

1. 左の「お客様のLINE画面」からメッセージを送る（サンプル文のワンクリック投入ボタンつき）
2. 疑似AIが内容を分類（営業時間／料金／予約／アクセス／その他）し、返信の **下書き** を自動生成
3. 右の「管理者画面」に下書きと通知ログが届く
4. 管理者が内容を確認・編集し、「このまま送信」を押すと、お客様の画面に返信が届く

ポイントは **「AIが下書きまで、送信は人が確認してから」** という設計です。自動送信の事故を防ぎながら、返信作成の手間だけを大きく減らせます。

## 起動方法

```bash
python3 app.py
# → http://localhost:8000 をブラウザで開く
```

Python標準ライブラリのみで動作し、外部依存はありません（ポートは環境変数 PORT で変更可能）。

## 実案件での構成

実際の導入では、次のような構成になります。

- お客様のメッセージ受信：LINE Messaging API（Webhook）
- 下書き生成：LLM（ChatGPT等）。営業時間・料金表などの店舗情報を根拠に回答を生成し、根拠がない内容は「担当者確認」の下書きにする
- 管理者の確認・送信：管理画面またはLINE通知から承認し、Messaging APIで送信
- ログ保存：問い合わせと返信の履歴を蓄積し、よくある質問の改善に活用

## テスト

```bash
python3 -m unittest discover -s tests -v
```

キーワード分類・下書き生成・承認フロー（送信／編集して送信／二重送信の防止）などを検証しています。
