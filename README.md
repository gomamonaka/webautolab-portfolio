# webautolab-portfolio — 業務自動化・Web制作 ポートフォリオ

中小企業・個人事業主の **「手作業の繰り返し業務」をツール化する** 業務委託エンジニアのデモ集です。
すべてのデモは架空データで構成されており、そのままダウンロードして動作確認できます。

> ご依頼・ご相談は [プロフィール](https://github.com/gomamonaka) をご覧ください。
> メニューと価格目安：お試し自動化 49,800円〜（3〜5日納品）／ 標準パッケージ 148,000円〜 ／ 月額保守 30,000円〜

## デモ一覧

### 1. [ai-classify](ai-classify/) — 問い合わせ・自由記述をAI分類しExcel化
問い合わせCSV/ExcelをAI（Claude / GPT）で分類し、**カテゴリ・要約（40字以内）・緊急度・返信要否・返信案の下書き**まで付けたExcelを出力します。集計シート（グラフ付き）と実行ログ（コスト概算）も自動生成。カテゴリ定義はYAMLで業種に合わせて変更可能で、Windowsではダブルクリック運用・exe化にも対応しています。

### 2. [excel-tool](excel-tool/) — Excel/CSVデータ整形・レポート自動化
表記ゆれだらけの売上CSVを自動クリーニング（日付表記の統一・和暦対応、全角→半角、重複削除、商品名の表記ゆれ統一、金額テキストの数値化）し、**月別・商品別の集計とグラフ付きExcelレポート**を生成します。何件どう直したかのクリーニングログも残ります。

### 3. [chrome-automation](chrome-automation/) — Chromeの定型作業を1クリックで自動化
Chrome拡張機能（Manifest V3）で、一覧ページのCSV保存と、CSVからのフォーム自動入力・連続登録をワンクリック化するデモです。動作確認用のダミー顧客管理システム同梱。対象URLやセレクターは設定画面からコード変更なしで変更できます。

### 4. [scraper](scraper/) — Webスクレイピング・データ収集
商品データ（タイトル・価格・評価・在庫）を自動収集しCSV/Excelに出力するPythonツール。**レート制限・指数バックオフ付きリトライ・robots.txt / 利用規約の遵守**を前提にした、実案件にそのまま流用できる設計です（対象はスクレイピング練習用サイト）。

### 5. [repair-case](repair-case/) — 動かなくなったツールの復旧ケーススタディ
「AIで作ったツールが止まった」「作った人が退職した」ツールを、最短3日で診断・修理・再発防止まで行うサービスの実例です。壊れた状態（before）と修理後（after）、診断レポート、修正差分、実行ログを収録しています。対象：GAS / Python / Node.js / スクレイパー / API連携スクリプト。

### 6. [ai-agent-flow](ai-agent-flow/) — AI社員タスクパイプライン
調査→要約→原稿→整合性確認を役割別エージェントで順に処理するPythonの参照実装。SQLiteキュー、入出力契約の検証、失敗時の再試行と通知、状態を確認できるHTMLダッシュボード付き。API課金なしで流れを確認できるstubモードがあります。

### 7. [gas-invoice](gas-invoice/) — 請求書の自動発行（Google Apps Script）
スプレッドシートの請求データから、請求書PDFの生成とGmail下書き（PDF添付）の作成までを自動化するGASのデモ。請求先ごとのグループ化・請求書番号の採番・消費税計算・処理ログつきで、送信はせず下書きまでに留める安全設計です。

### 8. [web-app-demo](web-app-demo/) — 小規模Webアプリ（備品貸出管理）
Python標準ライブラリだけで構築した社内向けWebアプリのデモ。備品の登録・貸出・返却、期限切れの強調表示、検索、CSVエクスポートを備え、単体テスト13件つき。「紙やExcelで回している業務を小さなWebシステムに置き換える」ご相談の参考例です。

### 9. [lp-sample](lp-sample/) — LP制作サンプル
ランディングページの制作サンプル（HTML/CSS）です。
